# Code of Conduct

This project expects respectful, constructive, and good-faith collaboration.

## Expected behavior

- Be kind and professional.
- Assume good intent, but accept correction.
- Keep discussions focused on the project.
- Give clear technical feedback without personal attacks.
- Respect privacy, security boundaries, and licensing terms.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Spam, trolling, or intentionally disruptive behavior.
- Attempts to bypass security, licensing, or access restrictions.

## Enforcement

Project maintainers may edit, hide, close, or remove issues, pull requests, and
comments that violate this code of conduct. Repeated or severe violations may
result in being blocked from participating.
