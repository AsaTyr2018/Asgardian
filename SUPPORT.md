# Support

Asgardian is a self-hosted, source-available project.

## Community support

Use GitHub issues for:

- reproducible bugs
- feature requests
- documentation improvements
- deployment questions that do not expose private infrastructure

## Not suitable for public issues

Do not post:

- secrets, credentials, private keys, or tokens
- private hostnames, private IP addresses, or internal diagrams
- generated private media or user data
- vulnerability details

Use a private maintainer contact for security or commercial licensing questions.
